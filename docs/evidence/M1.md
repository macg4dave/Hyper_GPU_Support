disks, current drivers, payload paths, counts and digests are discovered rather
than required operator inputs. Installation validates schema, bounded target count,
case-insensitive unique VM GUIDs, Generation 2 and exact discovered GPU interfaces
before publishing protected enrollment. The runner independently authorizes each
request against that enrollment.

enrollment, fixed dispatch, authenticated local pipe, ACLs, artifact integrity,
serialization and product/laboratory separation. Its durable-audit finding was
fixed and reviewed before live qualification. Protected admission records precede
dispatch; terminal outcomes precede replies. Credentials, raw errors and response
payloads are excluded. Interrupted work retains `Started`; publication errors
cannot report success. No blocking findings remain; the reviewer cleared M1 closure.

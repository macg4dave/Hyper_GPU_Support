# GUI documentation maintenance brief

Use this brief only for requested GUI documentation work. For implementation use
the [Slint prompt](../.github/prompts/SLINT_CODEX_PROMPT.md).

[ROADMAP](ROADMAP.md) owns priorities, [BACKLOG](BACKLOG.md) owns tasks and
[GUI_GUIDE](GUI_GUIDE.md) freezes the existing interface. Follow [AGENTS](../AGENTS.md)
and relevant [ENGINEERING](ENGINEERING.md) sections.

- Update only affected current descriptions against actual source. Distinguish
  implemented, simulated, unsupported and validation-pending behavior.
- Preserve historical records and the rewritten roadmap/backlog; correct only
  demonstrable factual drift. Do not turn old evidence into a new task queue.
- Keep security, recovery, truthful provider units and live/mock boundaries intact.
  Do not add pages, controls, processes or qualification requirements.
- Documentation work does not trigger builds, tests, GUI launches or live tests.
  Refer to AGENTS for testing and permission policy rather than duplicating it.
